# G5L12 생성 및 검수

## 입력과 구성

- 단원: Lesson 12. What Do You Want to Do?
- 입력: 해당 폴더의 1차시 Fun Talk & 찬트 HWP와 2차시 Real Talk & 파닉스 HWP.
- 입력은 빈칸이 이미 있는 원본 학습지이다. 대화 영역만 사용하고 찬트·파닉스는 제외했다.
- Fun Talk: 3개 장면, 17개 발화, 빈칸 6개.
- Real Talk: 4개 장면, 20개 발화, 빈칸 6개.
- 원본의 영어 발화·장면·빈칸 위치를 유지하고, 발화 중간의 편집상 줄바꿈을 공백으로 연결했다.
- 원본에 해석이 없어 한글 해석을 새로 작성했다. 교과서 페이지는 자료에서 확인되지 않아 넣지 않았다.

## 정답 대응

원본 보기와 문법·대화 문맥에 대응시켜 정답을 구성했다. 공식 정답지나 완전한 별도 대본으로 대조한 것은 아니다.

| 번호 | Fun Talk | Real Talk |
|---|---|---|
| 1 | learn | town |
| 2 | website | trip |
| 3 | go ice-skating | take a walk |
| 4 | go hiking | go fishing |
| 5 | make | take a picture |
| 6 | film | vacation |

- 원본 보기의 여섯 항목을 각 영역에서 한 번씩 사용했다.
- 여러 단어인 표현은 문항 하나로 유지하고, 단어별 밑줄을 배치했다.

## 출력물 및 페이지 검수

G5L9의 기존 HWPX 표·글자·문단 서식을 활용하고 G5L11의 최종 배치 방식을 적용했다.

| 파일 | 한글 해석 | 보기 목록 | HOP 페이지 수 |
|---|---|---|---:|
| Dictation(1).hwpx | 있음 | 있음 | 1 |
| Dictation(2).hwpx | 있음 | 없음 | 1 |
| Dictation(3).hwpx | 없음 | 있음 | 1 |
| Dictation(4).hwpx | 없음 | 없음 | 1 |
| Teacher_Answers.hwpx | 있음 | 본문 정답 및 정답 목록 | 1 |

- 페이지 상단에 공통 단원 제목을 두고 Fun Talk·Real Talk를 좌우 표에 배치했다.
- 괄호 해석은 영어 발화와 같은 문단에 배치했다. 기존 글자 크기·줄 간격·표 여백·용지 설정은 축소하지 않았다.
- 반·번호·이름 작성란, ‘검토용 초안’ 표시 및 ‘보기:’ 접두어는 넣지 않았다.
- HOP에서 다섯 파일을 각각 열어 1페이지임을 확인했다. 버전 1의 마지막 장면과 하단 보기 목록이 페이지 안에 표시되는 것을 화면으로 확인했다.
- 한컴 한글 및 실제 프린터 출력은 확인하지 않았다.

## 파일 검증과 재생성

- ZIP 무결성과 모든 XML 파싱을 검사했다.
- 영역별 문항 번호 1~6 및 네 버전의 영어 대화·빈칸 일치를 확인했다.
- 번역 문장 수와 원본 발화 수의 대응을 확인했다.
- 생성 코드: `scripts/generate_g5l12.py`. Python의 `olefile`, `lxml`이 필요하다.
- 기존 출력물이 있으면 기본적으로 중단하며, `--replace` 사용 시 백업 후 갱신한다. 이번에는 새 파일만 생성해 백업 파일이 없다.
