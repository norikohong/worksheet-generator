# 워크시트 만들기

기존 대본과 학습지의 구성 및 변형 규칙을 분석하여, 새로운 대본에서 워크시트를 생성하는 것이 이 프로젝트의 목적이다.

## 저장소 및 후속 작업

- Git remote 이름: `origin`
- 저장소 주소: https://github.com/norikohong/worksheet-generator.git
- 사용자가 새 대본을 전달하면 이 문서의 분석과 기존 워크시트 서식을 기준으로 워크시트를 만든다.
- 별도 요청이 없으면 대화 빈칸 문제를 해석·보기 유무에 따른 네 가지 버전으로 구성하고 교사용 정답지를 함께 만든다.
- 학년·단원·핵심 표현은 제공된 대본에서 확인하고, 문항 선정에 필요한 정보가 부족한 경우에만 추가로 확인한다.

## 자료 구성 및 분류 기준

각 폴더는 학년(Grade)과 단원(Lesson)별 자료를 포함한다. 예를 들어 `G5L8`은 5학년 8단원이다.

파일은 다음 세 종류로 구분한다. 파일명은 분류의 단서로 사용하되, 최종적으로는 본문에 완전한 대본이 있는지, 이미 빈칸 문제가 있는지 확인한다.

| 구분 | 파일명 및 위치 | 실제 내용 |
|---|---|---|
| 원문 대본 | `G4L8/영어4_최_08_대화문 및 해석.hwp` | 빈칸 없는 영어 대본과 한글 해석 |
| 원본 학습지 | 5·6학년 폴더의 `*워크시트*.hwp` | 보기와 빈칸이 있는 대화 활동 및 찬트·파닉스 활동 |
| 변형 워크시트 | `*Worksheet*.hwpx`, `Dictation(*).hwpx` | 해석과 보기 제공 여부를 달리한 네 가지 버전 |

`Dictation` 또는 `Worksheet`가 파일명에 없다는 이유만으로 대본으로 분류하지 않는다. 특히 한글 이름의 `워크시트` HWP는 완전한 원문 대본이 아닌 원본 학습지이다.

## 원본 학습지와 변형 워크시트의 관계

- G4L8은 원문 대본의 Fun Talk와 Real Talk를 활용한 워크시트가 있다.
- 5·6학년 Dictation은 두 차시 원본 학습지의 대화 부분을 하나로 합친 구성이다. 원본의 찬트·파닉스 활동은 포함하지 않는다.
- 기존 빈칸을 유지하는 경우 외에 빈칸을 추가하거나 해석을 다듬은 경우도 있으므로, 원본을 그대로 복사한 결과로 보지 않는다.

현재 자료는 출력 형식과 버전별 변형 규칙을 파악하는 데 활용할 수 있다. 다만 5·6학년 자료에는 이미 빈칸이 있으므로, 원문 복원이나 빈칸 선정 기준을 확정하려면 완전한 대본 또는 정답 확인이 추가로 필요하다.

## 분석 범위와 결론

6개 폴더의 HWP 11개와 HWPX 24개에서 본문을 추출하여 비교했다. 분석 결과, 새로운 대본에서 현재 자료와 같은 유형의 워크시트를 생성할 수 있는 공통 규칙을 확인했다.

문제 내용 생성과 한글 문서의 인쇄 레이아웃 재현은 별도로 구현하고 검증해야 한다. 이번 분석은 본문과 문서 구조를 기준으로 했으며, 한글 프로그램에서의 실제 인쇄 모양은 확인하지 않았다. 아래 구현 방안은 분석에 따른 제안이며, 생성 기능이 구현된 상태를 의미하지 않는다.

## 버전별 공통 규칙

| 버전 | 한글 해석 | 보기 단어 |
|---|---|---|
| LEVEL 1 / Dictation(1) | 있음 | 있음 |
| LEVEL 2 / Dictation(2) | 있음 | 없음 |
| LEVEL 3 / Dictation(3) | 없음 | 있음 |
| LEVEL 4 / Dictation(4) | 없음 | 없음 |

같은 단원에서는 대화 내용과 빈칸 위치를 유지하고, 한글 해석과 보기 제공 여부를 바꾼다. 따라서 하나의 문제 구성을 만든 뒤 네 가지 버전으로 출력할 수 있다.

### 단원별 대화 빈칸 수

| 단원 | Fun Talk / Story 1 | Real Talk / Story 2 | 합계 |
|---|---:|---:|---:|
| G4L8 | 8 | 8 | 16 |
| G5L8 | 7 | 8 | 15 |
| G5L9 | 6 | 6 | 12 |
| G5L10 | 6 | 6 | 12 |
| G6L8 | 6 | 8 | 14 |
| G6L9 | 7 | 6 | 13 |

위 수치는 변형 워크시트의 대화 영역을 기준으로 하며, 찬트·파닉스 등 별도 활동은 제외한다. 각 대화 영역에서 문항 번호는 다시 시작한다.

`baseball park`, `stronger than`, `in front of`처럼 여러 단어로 된 표현도 하나의 문항이 될 수 있다. 밑줄 개수와 문항 수를 구분하고, 정답을 단어뿐 아니라 구 단위로도 관리해야 한다.

## 기존 HWPX의 세부 문서 구조

아래 내용은 6개 단원의 HWPX 24개에서 본문과 XML의 표 구조를 조사한 결과이다. 용지 설정은 G4L8 LEVEL 1과 G5L10 Dictation(1)·(4)에서 확인한 값이며, 실제 인쇄 결과나 전체 파일의 페이지 수를 검증한 것은 아니다.

### 5·6학년 Dictation

두 차시의 대화를 하나의 **2열 표**에 좌우로 배치한다. 문서의 다단 설정이 아니라 표의 셀로 대화 영역을 나눈 구조이다.

| 위치 | 왼쪽 열 | 오른쪽 열 |
|---|---|---|
| 첫째 행 | Story 1 또는 Fun Talk의 제목·교과서 페이지와 장면별 대화 | Story 2 또는 Real Talk의 제목·교과서 페이지와 장면별 대화 |
| 둘째 행: 보기 제공 버전에만 존재 | 왼쪽 대화의 보기 단어·표현 | 오른쪽 대화의 보기 단어·표현 |

- Dictation(1)·(3)은 보기 행을 포함한 **2행 × 2열** 표이다.
- Dictation(2)·(4)는 보기 행을 제거한 **1행 × 2열** 표이다.
- 각 대화 셀 안에서 제목과 페이지, `[장면 1]` 등의 장면 표시, `화자: 영어 발화` 순으로 내용을 구성한다.
- 해석 제공 버전은 영어 뒤 괄호 안이나 다음 줄에 한글 해석을 넣는다.
- 빈칸은 `⑴_______________` 등의 형태로 표시하고, 각 대화 영역에서 번호를 다시 시작한다. 여러 단어인 정답에는 밑줄을 여러 개 사용하기도 한다.
- 보기는 각 대화에 대응하는 단어와 구를 나열하며, 정답 순서대로 나열된 것으로 가정하지 않는다.
- 원본 학습지의 찬트·파닉스 활동은 포함하지 않는다.

구조 참고 파일은 `G5L10/Dictation(1).hwpx`와 `G5L10/Dictation(4).hwpx`이다. 두 파일의 용지 설정은 A4 세로이며 상하좌우 여백은 약 10mm, 머리말·꼬리말 여백은 0이다. 새 5학년 단원은 기존 5학년 Dictation을 템플릿으로 활용하되, 대본 길이에 따른 줄바꿈과 페이지 넘김을 별도로 확인한다.

### 4학년 G4L8 LEVEL 워크시트

5·6학년의 좌우 대화 배치와 달리, 어휘 활동과 두 대화 활동을 다음 순서로 구성한다.

1. 단원 제목과 Class·Name 작성란: **1행 × 2열** 표
2. New Word: 단어 10개의 뜻을 적는 **5행 × 4열** 표. 각 행에 `단어 / 뜻 작성란 / 단어 / 뜻 작성란`을 배치
3. Word Search 활동
4. Fun Talk: 교과서 페이지와 안내 문구, 보기 및 장면별 대화 표
5. Real Talk: 교과서 페이지와 안내 문구, 보기 및 장면별 대화 표

- 각 대화 표는 **6행 × 5열** 구조이다. 위쪽 두 행은 보기 영역이며, 왼쪽의 ‘보기’ 셀은 두 행을 병합하고 나머지 셀에 단어 8개를 배치한다.
- 아래 네 행은 장면별 대화이다. 왼쪽 셀에 장면 번호를 넣고, 오른쪽 네 열을 병합한 셀에 해당 장면의 대화를 넣는다.
- 빈칸 번호는 `❶`, `❷` 등의 형태이며 Fun Talk와 Real Talk에서 각각 다시 시작한다.
- LEVEL 2·4는 보기 단어를 지우지만 **‘보기’ 제목과 빈 셀은 유지**한다. 보기 행 자체를 제거하는 5·6학년과 구분한다.
- LEVEL 3·4에서는 한글 해석을 제거한다. New Word와 Word Search 활동은 네 버전에 공통으로 존재한다.

`G4L8/'1 New word Worksheet (LEVEL 1).hwpx`의 용지 설정은 A4 세로, 상하좌우 여백 약 5mm, 머리말·꼬리말 여백 0이다. 이 어휘·퍼즐 구성은 기존 자료의 특징이며, 새 워크시트 생성 시 기본 범위인 대화 빈칸 문제에 자동으로 추가하지 않는다.

### 템플릿 활용 시 유의 사항

- G5L11 생성 시에는 양쪽 대화 셀에 반복된 단원 제목을 페이지 상단의 공통 제목으로 통합했다. 해석을 영어 옆에 붙인 상태에서 글자 크기·간격 축소 없이 HOP 기준 네 버전과 정답지가 각각 한 페이지에 들어가는 것을 확인했다.

- 학년과 활동 구성에 맞는 기존 HWPX를 선택하고, 표·셀 병합과 문단 서식을 유지하면서 내용을 교체한다.
- HWPX의 `Contents/section0.xml`에는 본문과 표 구조, `Contents/header.xml`에는 글꼴·문단 등 서식 정의가 있다. `Preview/PrvText.txt`는 본문 전체를 포함하지 않을 수 있으므로 분석·검수의 유일한 근거로 사용하지 않는다.
- 현재 자료 목록에는 별도의 교사용 정답지가 없다. 정답지는 추가 생성 대상이며 기존 정답지 서식이 있다고 가정하지 않는다.
- XML의 구조가 정상이어도 인쇄 레이아웃이 보장되지는 않는다. 한글에서 표 잘림, 줄바꿈 및 페이지 넘김을 검증한다.

### 한 페이지로 조정하는 순서

워크시트는 버전별 한 페이지로 작성하되, 읽기 편한 기존 글자 크기와 간격을 우선 유지한다. 다음 순서로 조정하고 단계마다 문서 앱에서 실제 페이지 수와 잘림 여부를 확인한다.

1. **해석을 영어 옆에 배치:** 괄호 해석을 해당 영어 발화와 같은 문단에 이어 붙인다. 별도 해석 문단을 만들지 않으며, 긴 문장은 자연스럽게 줄바꿈되도록 한다. 기존 글자 크기·줄 간격·표 여백·용지 설정은 유지한다.
2. **한 페이지 여부 확인:** 이 상태로 한 페이지에 들어가면 조정을 끝낸다. 글자 크기나 간격을 추가로 줄이지 않는다.
3. **반복 제목 통합:** 페이지가 넘치면 양쪽 대화 셀에 반복된 단원 제목을 페이지 상단에 한 번만 배치한다. 각 대화의 Fun Talk·Real Talk 제목, 장면 구분과 문항은 유지한다.
4. **남은 넘침만 최소 조정:** 여전히 넘치는 경우에만 불필요한 빈 문단과 줄바꿈을 정리하고, 필요한 최소 범위에서 여백·문단 간격을 조정한다. 글자 크기와 줄 간격 축소는 마지막 수단으로 사용하며 가독성을 우선한다. 원문·해석·문항·보기를 생략해 맞추지 않는다.
5. **모든 출력물 재검수:** 네 버전과 교사용 정답지를 각각 다시 열어 한 페이지인지 확인한다. 마지막 장면, 보기 및 정답 목록이 페이지 안에 표시되고 표나 글자가 잘리지 않는지 확인한다. 검수 기록에 사용한 앱, 페이지 수, 조정 내용 및 미확인 사항을 남긴다.

## 자동화 가능 범위

| 작업 | 판단 및 필요한 조건 |
|---|---|
| 대화 영역·장면·화자 구분 | 가능. 입력 대본의 형식별 처리 필요 |
| 지정한 단어·표현을 빈칸으로 변환 | 규칙으로 처리 가능 |
| 보기·문항 번호·정답지 생성 | 자동화 가능. 정답지는 추가 출력 기능으로 제안 |
| 해석·보기 조합으로 네 가지 버전 생성 | 자동화 가능 |
| 새 대본에서 학습 목표에 맞는 빈칸 선정 | 학습 목표, 핵심 표현, 문항 수 등의 기준 또는 AI 판단 필요 |
| 한글 해석 생성 | 원문에 해석이 없으면 번역과 검수 필요 |
| 기존 형식의 HWPX 출력 | 기존 서식을 템플릿으로 활용하는 방식이 적합. 한글에서 출력 검증 필요 |
| 단어 찾기·그림 기반 활동 생성 | 별도의 퍼즐 생성 및 이미지 처리 필요 |

G4L8의 단어 목록과 Word Search는 대화 빈칸 문제와 별도 활동이다. 대화문에 나온 단어만으로 단원 전체의 학습 어휘를 확정하기 어려우므로, 단원 핵심 어휘를 추가 입력으로 받는 방식이 적합하다.

## 자료에서 확인된 예외와 검수 항목

- **추가 빈칸:** G6L9 원본 HWP에서 그대로 남아 있던 `library`가 Dictation에서는 빈칸으로 바뀌었다. 기존 빈칸 복사 외에 새로운 문항 선정이 필요할 수 있다.
- **보기 오탈자 의심:** G5L8의 보기에는 문맥상 `glasses`로 보이는 항목이 `lasses`로 적혀 있다. 정답 확정 시 확인이 필요하다.
- **본문 및 장면 번호 오류:** G5L10 Dictation에는 `my om and dad`라는 오탈자가 있으며, Story 2의 마지막 장면이 다시 `[장면 3]`으로 표시되어 있다.
- **해석 표현 차이:** G4L8은 원문 대본의 해석을 그대로 복사하지 않고 자연스럽게 다듬은 표현이 있다.
- **선택적 내용 사용:** 원본에 있는 찬트·파닉스 활동이 Dictation에는 없으므로, 생성 대상 영역을 명시적으로 선택해야 한다.

기존 자료를 검수 없이 정답으로 사용하지 않는다. 원문과 출력의 차이, 오탈자, 문항 번호, 빈칸과 정답·보기의 대응을 확인하는 절차가 필요하다.

## 권장 구현 흐름

1. **대본 입력:** 영어 대본과 제공된 한글 해석을 읽고, 학년·단원명·페이지·핵심 표현·문항 수를 설정한다.
2. **내용 구조화:** 대화 영역, 장면, 화자, 영어 발화, 한글 해석을 구분한다.
3. **빈칸 후보 선정:** 핵심 단어와 구를 후보로 고르고 학습 목표와 문항 수에 맞게 확정한다.
4. **문제 및 정답 구성:** 빈칸 위치와 정답을 함께 관리하고, 보기와 영역별 문항 번호를 만든다.
5. **버전별 출력:** 같은 문제 구성을 바탕으로 해석·보기 유무에 따른 네 가지 HWPX와 교사용 정답지를 생성한다.
6. **결과 검증:** 원문 보존, 정답 대응, 보기 누락, 번호 순서를 확인하고 한글에서 표·줄바꿈·페이지 넘김을 검증한다.

초기 구현 범위는 대화 빈칸 문제 네 가지 버전과 교사용 정답지로 잡는 것이 적합하다. 문서 출력에는 기존 HWPX 서식을 템플릿으로 활용하고, 단어 찾기·찬트·파닉스·그림 활동은 후속 범위로 분리한다.

핵심 선행 과제는 빈칸 선정 기준을 정하는 것이다. 이후 대본 길이가 달라져도 문서가 정상적으로 출력되는지 검증해야 한다.
