# G5L11 생성 및 검수

현재 생성물은 **검토용 초안**이다. 원본 HWP 두 개의 대화 영역만 사용했으며 원본 파일은 변경하지 않았다.

## 구성

- Dictation(1): 해석 있음 / 보기 있음
- Dictation(2): 해석 있음 / 보기 없음
- Dictation(3): 해석 없음 / 보기 있음
- Dictation(4): 해석 없음 / 보기 없음
- Teacher_Answers: 교사용 정답 및 해석
- Fun Talk 3개 장면, Real Talk 5개 장면. 원본의 빈칸을 영역별 4개씩 유지했다.
- G5L9의 버전별 HWPX를 템플릿으로 사용했다. 두 대화를 좌우 표에 배치하고 보기 제공 버전에만 보기 행을 두었다.

## 적용한 내용 및 확인할 사항

- Fun Talk 정답 후보: 1 see / 2 bedroom / 3 window / 4 living room
- Real Talk 정답 후보: 1 bathroom / 2 bedroom / 3 kitchen / 4 garden
- 정답은 원본 보기와 문맥을 바탕으로 적용한 후보이며 사용자 또는 공식 대본의 확인이 필요하다. 특히 Real Talk 1·4는 장면 영상이나 완전한 대본으로 확인해야 한다.
- Real Talk 원본 제목은 ‘Lesson 11. I’m in the Sixth Grade’로 Fun Talk 제목과 달랐다. 출력물은 Fun Talk의 ‘What’s in the Kitchen?’으로 통일했다.
- 원본에는 한글 해석이 없어 새로 번역했다. 영어 발화는 원본을 유지했고, 이어지는 줄은 한 발화로 합쳤다.
- 교과서 페이지는 입력 자료에서 확인되지 않아 표기하지 않았다.
- 찬트·파닉스 활동은 제외했다.

## 검수 결과

- 5개 HWPX의 ZIP 무결성과 XML 파싱을 확인했다.
- 네 문제 버전에서 영어 대화 및 빈칸 위치가 동일한지 확인했다.
- 각 대화 영역의 문항 번호 1~4를 확인했다.
- 이전 단원의 텍스트 미리보기를 새 내용으로 교체하고, 기존 이미지 미리보기와 줄 배치 캐시는 제거했다.
- 초기 생성 시에는 문서 앱 검증을 하지 않았으며, 이후 HOP에서 갱신본 5개를 열어 각각 1페이지임을 확인했다. 아래 최종 검수 결과를 참고한다.

생성 코드는 `scripts/generate_g5l11.py`에 있다. 실행에는 `olefile`, `lxml`이 필요하며 기존 생성물이 있으면 기본적으로 중단한다. `--replace`를 지정하면 기존 파일을 `.backups/날짜-시간/`에 백업한 뒤 갱신한다.

## 해석 배치 조정 및 서식 복원

- 괄호 해석만 영어 발화와 같은 문단에 이어 붙였다.
- 이전에 적용한 본문 9pt·제목 11pt, 줄 간격 115%, 문단 간격·들여쓰기 변경을 되돌렸다. 글자 크기와 문단 서식은 G5L9 원본 템플릿 값을 그대로 사용한다.
- 용지 설정, 표 크기 및 셀 여백도 G5L9 원본 템플릿 값으로 복원했다.
- 네 버전과 교사용 정답지를 다시 생성했다. 직전 생성물은 `.backups/`에 보관했다.
- 원본 템플릿과 서식·용지·표 크기·셀 여백 일치 여부, ZIP/XML 및 버전 간 영어 대화·빈칸 일치를 검사했다.
- 해석 배치만 변경한 중간본은 HOP에서 2페이지였으며, 보기가 다음 페이지로 밀렸다. 아래 제목 배치 조정으로 해결했다.

## 최종 페이지 검수 (HOP)

- 양쪽 대화 셀에 반복되던 긴 단원 제목을 없애고 페이지 상단의 공통 제목으로 통합했다. 단원명·버전·검토용 초안 표시는 유지했다.
- 영어 옆 괄호 해석 배치를 유지했다. 기존 글자 크기, 줄 간격, 문단 서식, 용지 설정, 표 크기 및 셀 여백은 줄이지 않았다.
- HOP에서 파일을 각각 다시 열어 페이지 수를 확인했다.

| 파일 | HOP 페이지 수 |
|---|---:|
| Dictation(1).hwpx | 1 |
| Dictation(2).hwpx | 1 |
| Dictation(3).hwpx | 1 |
| Dictation(4).hwpx | 1 |
| Teacher_Answers.hwpx | 1 |

- 버전 1의 마지막 장면과 보기, 교사용 정답지의 마지막 장면과 정답 목록이 페이지 안에 표시되는 것을 화면으로 확인했다.
- HOP 화면 기준 검증이며, 한컴 한글 및 실제 프린터 출력은 확인하지 않았다. 정답 후보의 원문 확인 필요 상태도 유지한다.

## 백업 정리

- 사용자 요청에 따라 `.backups/`의 이전 생성물 15개와 백업 폴더를 삭제했다. 현재 최종 워크시트 4종과 교사용 정답지는 유지했다.

## 작성란 제거

- 사용자 요청에 따라 워크시트 4종과 교사용 정답지에서 반·번호·이름 작성란을 제거했다.
- 생성 코드와 README의 기본 작성 기준에도 반영했다. 대화·문항·정답 및 기존 글자 크기와 간격은 유지했다.

## 표시 문구 정리

- 사용자 요청에 따라 모든 출력물 제목에서 ‘검토용 초안’ 표시를 제거했다. 정답 후보의 추가 확인 필요 상태는 유지한다.
- 하단 보기 단어 목록은 유지하고 ‘보기:’ 접두어만 제거했다. 생성 코드와 텍스트 미리보기에도 반영했다.
